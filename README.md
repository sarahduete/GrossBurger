# 🍔 Gross Burger
Site institucional para hamburgueria

O Gross Burger é um projeto desenvolvido com o objetivo de criar uma presença digital para uma hamburgueria, apresentando sua identidade visual, seus produtos e suas principais informações.

🔗 **[Acessar o site](https://grossburgerbrasil.netlify.app/)**

## 📖 Sobre o projeto

O Gross Burger surgiu da proposta de desenvolver um site institucional que representasse a personalidade da hamburgueria e aproximasse a marca de seus clientes.

A ideia foi criar uma página que valorizasse o estilo da marca, destacando os hambúrgueres, o cardápio e as informações de contato em um único ambiente.

## 💻 Como foi desenvolvido

O desenvolvimento começou com o planejamento da estrutura do site e a definição da identidade visual.

Busquei uma estética inspirada nas hamburguerias americanas, utilizando principalmente preto, vermelho e tons de creme. A proposta foi criar uma aparência marcante, com tipografia forte, imagens em destaque e elementos que combinassem com a identidade da Gross Burger.

Depois, desenvolvi a estrutura das páginas utilizando HTML, organizando as seções de apresentação, história da marca, cardápio, diferenciais e contato.

Com o HTML estruturado, trabalhei na estilização utilizando CSS, ajustando espaçamentos, tamanhos, imagens e elementos visuais para criar uma navegação agradável.

Também utilizei JavaScript para implementar interações na navegação do site.

## ⚙️ Funcionalidades

- Apresentação da hamburgueria.
- Seção sobre a marca.
- Destaque para os hambúrgueres.
- Apresentação do cardápio.
- Galeria de imagens.
- Links para redes sociais.
- Informações de contato.
- Layout responsivo.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Utilização |
|---|---|
| HTML | Estrutura das páginas |
| CSS | Estilização e identidade visual |
| JavaScript | Interações e navegação |
